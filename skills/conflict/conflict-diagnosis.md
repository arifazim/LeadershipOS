# Skill: Conflict Diagnosis

**Domain**: Conflict Resolution
**Owner**: `subagents/engineering-manager.md`
**Cadence**: On-demand — run before any other conflict resolution skill

---

## Purpose

Classify the conflict, identify its root cause, assess severity, and route to the appropriate resolution approach — before any conversation is attempted — so that the response matches the actual nature of the conflict rather than its surface presentation.

**What the EM does automatically**: When conflict is detected or reported, the EM:
1. Classifies the conflict type (interpersonal, structural, procedural, values-based, resource)
2. Identifies the root cause — the structural or behavioral condition generating the conflict
3. Assesses severity and who is affected
4. Detects whether the EM is a party to the conflict (which changes the approach entirely)
5. Produces: root cause, conversation strategy, risks, desired outcome, and follow-up actions

**Ethical principle**: Diagnosis must be neutral. The EM who diagnoses conflict while already having a view of who is right will produce a biased assessment. Diagnosis requires gathering perspectives from all parties before forming conclusions. An unheard perspective is not the same as a wrong perspective.

### Required
| Input | Description |

| **Parties involved** | Who is in conflict — individuals, teams, or functions |

| Input | Description |
|---|---|
| **Prior resolution attempts** | What has been tried; what happened |
| **Organizational context** | Reporting relationships, power dynamics, prior history between parties |
| **Business impact** | Whether delivery, quality, or relationships are already damaged |

## Analysis

### Step 1 — Classify the Conflict Type

Different conflict types require different resolution approaches. Misidentifying the type produces the wrong intervention:

```
Type 1 — Interpersonal conflict
  Definition: Friction between specific individuals; often about communication style,
  respect, or perceived unfair treatment
  Signal: Tension is person-specific; same people in conflict repeatedly;
          conflict doesn't occur when these individuals are apart
  Resolution path: Direct facilitation; often private conversations before joint session
  → Invoke: skills/conflict/difficult-conversations.md or skills/conflict/mediation.md

Type 2 — Structural conflict
  Definition: Conflict generated by organizational design: overlapping ownership,
  ambiguous accountability, or competing incentives
  Signal: Different people in the same roles would generate the same conflict;
          conflict recurs after resolution attempts; structural condition unchanged
  Resolution path: Fix the structure, not the people
  → Invoke: skills/organizational/decision-network.md; skills/organizational/conflict-prediction.md

Type 3 — Procedural conflict
  Definition: Disagreement about how work gets done — process, standards, workflow
  Signal: Conflict is about "how" not "who"; both parties agree on goals but not methods;
          conflict increases at process boundaries
  Resolution path: Facilitate agreement on shared process; trial period + retrospective
  → Invoke: skills/conflict/team-alignment.md

Type 4 — Values-based conflict
  Definition: Conflict rooted in genuinely different values or professional ethics
  Signal: Both parties are internally consistent; conflict is about what is right, not just what works;
          resolution through compromise feels like violation to both parties
  Resolution path: Most difficult; may require escalation or structural separation
  Warning: Do not attempt to "resolve" a genuine values conflict as if it were interpersonal

Type 5 — Resource conflict
  Definition: Competition for finite resources — headcount, budget, timeline, capacity
  Signal: Both parties want the same resource; conflict would disappear if resource were abundant;
          conflict correlates with planning cycles and budget decisions
  Resolution path: Transparent prioritization; clear decision authority; escalation if authority unclear
  → Invoke: skills/organizational/decision-network.md
```

### Step 2 — Identify the Root Cause

```
Root cause categories:

Structural root cause (most common):
  Ownership not defined → Teams do the same work twice or not at all
  Incentives misaligned → Each team optimized correctly for their own metric; conflict at the seam
  Process not designed → Gap or overlap in workflow creates friction at the boundary

Communication root cause:
  Assumption not surfaced → Both parties working from different unstated beliefs
  Feedback not given → Small frustrations accumulated into resentment
  Information asymmetry → One party knows something the other doesn't; decisions appear inexplicable

Relational root cause:
  Trust broken previously → Old incident colors current interactions
  Style difference → One person's directness reads as aggression; one person's quiet reads as disengagement
  Perceived disrespect → Someone felt their work, judgment, or identity was dismissed

Historical root cause:
  Prior unresolved conflict → This conflict is actually a continuation of a previous one
  Pattern not addressed → Behavior has occurred before; no consequence or conversation resulted
```

### Step 3 — Assess Severity

```
Severity levels:

Level 1 — Team friction (manageable):
  Parties can still work together; delivery not significantly impacted
  Resolution: Team-level; EM facilitates directly
  Timeline: Address within 2 weeks

Level 2 — Team disruption (significant):
  Collaboration has degraded; some delivery impact; others are affected by the tension
  Resolution: EM-facilitated with structured process
  Timeline: Address within 1 week; escalate if not improving in 2 weeks

Level 3 — Organizational conflict (serious):
  Multiple teams or functions involved; delivery meaningfully impacted; leadership aware or should be
  Resolution: Requires manager above EM or cross-functional leadership involvement
  Timeline: Address immediately; escalate within 48 hours

Level 4 — HR or conduct level (critical):
  Behavior violates policy, law, or professional standards; individual safety or dignity at risk
  Resolution: HR required; EM should not attempt independent resolution
  Timeline: Escalate within 24 hours
```

### Step 4 — Detect Whether the EM Is a Party

```
If the EM is a party to the conflict:
  The EM cannot diagnose, mediate, or facilitate their own conflict neutrally
  Required: Ask manager above EM to facilitate or mediate
  Do NOT: Attempt to resolve a conflict in which you are a party using your authority

If the EM's team is in conflict with another team:
  The EM has a partial conflict of interest; should be transparent about it
  Recommended: Co-facilitate with the other team's EM
  Or: Bring in a neutral third party (skip-level or another EM)

If the conflict is within the EM's team and the EM is not a party:
  The EM facilitates directly
  → Proceed to route selection
```

## Decision Tree

```
What does the diagnosis reveal?

├── TYPE 4 (VALUES-BASED) OR LEVEL 4 (HR/CONDUCT)
│   └── Do not attempt resolution at team level
│       Level 4: Escalate to HR within 24 hours; document timeline and facts
│       Type 4: Escalate to leadership; be honest that resolution may not be possible
│       Frame: "I've diagnosed this as a values-based conflict that I cannot resolve
│       at my level. Here's what I've observed and what I recommend."

├── STRUCTURAL ROOT CAUSE
│   └── Fix the structure before facilitating the people
│       Order matters: Structural conflict will recur regardless of relationship quality
│       if the structure is not fixed
│       → Invoke: skills/organizational/decision-network.md for ownership clarity
│       → Invoke: skills/organizational/conflict-prediction.md for incentive misalignment

├── EM IS A PARTY
│   └── Step back; request facilitation from above
│       Be transparent: "I have a conflict of interest here and should not facilitate this."
│       Do NOT: Use authority to resolve a conflict in which you have a stake

├── LEVEL 3 (ORGANIZATIONAL)
│   └── Loop in manager or relevant cross-functional leader within 48 hours
│       Prepare the diagnosis: type, root cause, parties, business impact, what's been tried
│       → Invoke: skills/conflict/stakeholder-resolution.md

├── INTERPERSONAL, LEVEL 1–2
│   └── Check: Have both parties spoken directly? If not, start there.
│       → Invoke: skills/conflict/difficult-conversations.md if one party needs preparation
│       → Invoke: skills/conflict/mediation.md if direct conversation has failed or been attempted

└── PROCEDURAL OR RESOURCE, LEVEL 1–2
    └── → Invoke: skills/conflict/team-alignment.md for within-team procedural
        → Invoke: skills/organizational/decision-network.md for resource prioritization
```

## Confidence Score

| Condition | Modifier |
|---|---|
| All five conflict types assessed | Base: 65% |
| Root cause classified (structural vs. communication vs. relational) | +15% |
| Severity level assessed | +10% |
| EM conflict of interest checked | +10% |
| All five recommendations produced | +5% |
| Single-party perspective only | −25% |
| No root cause identified | −20% |
| EM attempting to resolve own conflict | −30% (disqualifying) |

## Failure Modes

| Mode | Symptom | Fix |
|---|---|---|
| **Single-party diagnosis** | Conflict classified from one party's account | Gather perspectives from all parties before classification. One account is a complaint; two accounts are a conflict. |
| **Interpersonal misdiagnosis** | Structural conflict treated as personality clash | If the conflict would occur with different people in the same roles, it's structural. Fix the structure. |
| **EM resolving own conflict** | EM facilitates a situation where they have a stake | Name the conflict of interest; step back; request neutral facilitation. |
| **Type 4 attempted at team level** | Values-based or conduct conflict handled informally | Level 4 requires HR. Values-based conflicts require leadership. Do not attempt alone. |
| **Severity underestimated** | Level 3 conflict handled as Level 1; escalation delayed | When in doubt, escalate the severity assessment. The cost of over-escalating is low. The cost of under-escalating is high. |
