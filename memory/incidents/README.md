# Incident Patterns

Recurring incident patterns — written by `kaizen/weekly-review.md` (Q6) and `loops/incident-loop.md` whenever an incident's root cause matches a prior occurrence.

**File naming**: `{{YYYY-MM-DD}}-{{incident-topic}}.md`

**Entry format**:
```
## {{Incident}}
**Prior occurrence**: {{date}}
**Same root cause?**: {{Yes/No}}
**Post-mortem action items completed?**: {{Yes/No/Partial}}
**Pattern**: {{what makes this recurring, not isolated}}
```
