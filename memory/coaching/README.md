# Coaching Patterns

Engineer growth patterns — what enabled the growth, so it can be reproduced deliberately rather than attributed to luck. Written by `kaizen/weekly-review.md` (Q5) and `loops/career-loop.md` / `loops/promotion-loop.md`.

**File naming**: `{{YYYY-MM-DD}}-{{pattern-topic}}.md`

**Entry format**:
```
## {{Growth observed}}
**Engineer**: {{name or role, anonymized if shared}}
**What enabled it**: {{coaching, opportunity, autonomy, challenge}}
**Reusable pattern**: {{what to do again with someone else}}
```
