# Decision Log (lightweight)

A lightweight cross-reference of decision outcomes tracked during routine kaizen/loop execution — distinct from the full structured records in `decision-memory/`. Written by `kaizen/weekly-review.md` and any loop's "Log outcome" step when a scope or trade-off decision was made.

**File naming**: `{{YYYY-MM-DD}}-{{decision-topic}}.md`

**Entry format**:
```
## {{Decision}}
**Context**: {{loop or review that surfaced it}}
**Outcome**: {{what happened}}
**Promote to decision-memory/?**: {{Yes/No — Yes if significant enough for the full schema}}
```

If a decision here turns out to be significant, promote it into `decision-memory/` via `skills/decision-memory/record-decision.md` rather than growing this log into a duplicate of that module.
