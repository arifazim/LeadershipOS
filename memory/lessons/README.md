# Lessons

Dated entries capturing a wrong prediction, a recommendation that worked, or a recommendation that failed — written by `kaizen/weekly-review.md` (Q1, Q3, Q4) and by any loop's "Log outcome" step.

**File naming**: `{{YYYY-MM-DD}}-lessons.md`

**Entry format**:
```
## {{Topic}}
**What happened**: {{outcome}}
**What we expected**: {{prediction or recommendation}}
**Why the gap**: {{root cause}}
**Applies to**: {{skill, subagent, or loop this should inform next time}}
```
